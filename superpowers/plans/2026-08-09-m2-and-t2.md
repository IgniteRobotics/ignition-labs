# M2 OOP, Interfaces & Lambdas + T2 Supplier-Swap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `projects/m2-oop/` (an L2 contract-and-build exercise: a Javadoc-only API specification, a read-only behavioural contract test that enforces it, a planted supplier bug, a starter test file, and a pinned reading assignment) and `projects/testouts/t2-supplier-swap/` (an interface with two implementations, a wiring seam, and a given test for the third), so a Track A/B student can work M2 end to end and a Track C/D student can test out of it.

**Architecture:** Two standalone GradleRIO projects, siblings under `projects/` (spec §4.2). M2 is L2 scaffold-fade, which is the first level where **the student writes the signatures** — so nothing in the skeleton may name them in code. That forces the one genuinely novel mechanism in this plan: `SensorProfileContractTest` reaches the student's class through `ContractProbe`, a given reflective helper, because a test that referenced `SensorProfile` directly could not compile on a clean clone. T2 avoids reflection entirely by putting the wiring seam in given code — the test asks a given factory for `"flat"` and never names the class the student writes.

**Tech Stack:** Java 17, GradleRIO 2026.2.1, Gradle 8.11, Spotless 8.2.1 (`googleJavaFormat 1.19.2`), JUnit Jupiter 5.10.1. No vendordeps in either project — M2 has no robot in it (spec §9.3), and robot code starts at M3.

## Global Constraints

Every task's requirements implicitly include this section.

- **Java toolchain.** Local Gradle runs need `export JAVA_HOME=~/wpilib/2026/jdk`. Without it the wrapper picks up a Java 11 JVM and both plugins fail to resolve with "Dependency requires at least JVM runtime version 17." This is an environment fact, not a build defect — do not "fix" `build.gradle` in response to it.
- **Versions are fixed** (spec §4.3): GradleRIO `2026.2.1`, Gradle wrapper `8.11`, `sourceCompatibility`/`targetCompatibility` 17, Spotless plugin `8.2.1`, `googleJavaFormat('1.19.2').reflowLongStrings()`, JUnit `org.junit.jupiter:junit-jupiter:5.10.1`. Never bump a version as part of this plan.
- **`enforceCheck false`, and never `compileJava.dependsOn 'spotlessApply'`** (spec §4.3). Auto-apply-on-compile and a real CI format check are mutually exclusive; wiring it back is the exact defect that made M0's gate unreachable.
- **Package naming** (spec §4.4): M2 sources live in `frc.training.m2`. T2 sources live in `frc.testout.t2`. Never `frc.robot` — these are pure exercises with no robot, and naming them `frc.robot` invites pasting training code into a season repo out of muscle memory.
- **Vendordeps: none** in either project (spec §9.3). No `vendordeps/` directory at all.
- **L2 means the student writes the signatures** (spec §8). No file in `projects/m2-oop/` may contain a compilable declaration of `SensorProfile` or of any of its members. `SensorProfileSpec.java` states the contract in prose — parameter names, parameter types, return types, behaviour, edge cases — and contains no method declarations to copy. This is the difference between L3 and L2 and it is the whole point of the milestone.
- **A stub never contains the answer in a comment** (spec §8). The contract states inputs, outputs and edge cases, never the implementation. No formula appears anywhere in `projects/m2-oop/`. This applies to Javadoc, inline comments, README text, and variable names.
- **A given test never asserts on implementation** (spec §8). It asserts on behaviour through the public API. `ContractProbe` is the one place reflection is permitted, and it is used to *locate* the public API, never to reach a private field or an internal method.
- **Every skeleton compiles on a clean clone** (spec §12.3). This includes `compileTestJava`. `./gradlew assemble` must be green, `./gradlew compileTestJava` must be green, and `./gradlew test` must be red — the red must come from failing assertions, never from a compile error. A Track A student cannot tell a compile error from a broken toolchain.
- **No test may assert that a stub throws.** A test asserting `UnsupportedOperationException` passes against the unmodified skeleton, which inverts the whole gate. Never write one.
- **Double assertions always use the delta overload:** `assertEquals(expected, actual, 1e-9)`. M2 is the milestone where a student first writes their own tests; the given tests must model the practice they will copy.
- **Committed Java must already be `googleJavaFormat` clean.** `skeleton-integrity.yml` exempts exactly one filename by convention — `FormatMe.java`, M0's formatting exercise — and nothing in M2 or T2 is named that. Every task that adds Java under `src/` ends by running `./gradlew spotlessApply` and committing the result. Files under `starter/` are outside Spotless's `src/**/*.java` target and must be hand-formatted to match.
- **No pre-2026 Ignite references** (spec §12.1). Every `Robot-2026` path referenced anywhere in this plan is pinned to commit `28ce5397d88275001d656dbb717d22cf9ac0150d` (2026-06-09), per spec §9.3 and acceptance criterion §14.
- **T2's README must never say what the third implementation is called or which file to change.** Naming the seam is the task.

Create `projects/m2-oop/src/main/java/frc/training/m2/SensorProfileSpec.java`:

```java
package frc.training.m2;

/**
 * The specification for the class you are going to write. This file is not that class — it is the
 * description of it, and it stays exactly as it is.
 *
 * <p>Create {@code SensorProfile.java} beside this file, in this same package, and give it the
 * public API described below. Nothing here is a method you can copy; deciding what each signature
 * has to look like is the exercise.
 *
 * <h2>What a sensor profile is</h2>
 *
 * <p>An encoder counts in ticks. A mechanism turns in rotations, and a gearbox sits between them.
 * Every subsystem on the robot needs the same four conversions and every one of them has different
 * numbers, so this is a class with state rather than a pile of static methods: you build one
 * profile per mechanism and ask it questions.
 *
 * <h2>Construction</h2>
 *
 * <p>A public constructor taking two things, in this order:
 *
 * <ul>
 *   <li>{@code ticksPerRotation}, an {@code int} — how many ticks the encoder reports for one full
 *       turn <em>of the motor shaft</em>. Greater than zero.
 *   <li>{@code gearRatio}, a {@code double} — how many turns of the motor make one turn of the
 *       mechanism. A ratio of 9.0 means the motor turns nine times per mechanism turn. Greater
 *       than zero.
 * </ul>
 *
 * <p>Both values are settings of one physical mechanism. They are decided when the profile is
 * built and they never change afterwards, and the class should say so in the way it declares them.
 * Every field must be private (M2's definition of done, and the contract test checks it).
 *
 * <h2>The conversions</h2>
 *
 * <p>Everywhere below, "rotations" and "RPM" mean the <em>mechanism</em>, not the motor. That is
 * what the rest of the robot cares about — nobody aims a shooter in motor turns.
 *
 * <ol>
 *   <li><b>{@code ticksToRotations}</b> — takes an {@code int} raw encoder reading, which may be
 *       negative, and returns a {@code double}: how far the mechanism has turned. The fractional
 *       part is part of the answer. A reading of one quarter of a motor turn is not zero.
 *   <li><b>{@code rotationsToTicks}</b> — the inverse. Takes a {@code double} count of mechanism
 *       rotations and returns an {@code int} encoder reading. An encoder cannot report a fraction
 *       of a tick, so the answer is the <em>nearest</em> whole tick, not the one below it.
 *   <li><b>{@code ticksPer100msToRpm}</b> — takes an {@code int}, a change in the encoder reading
 *       measured over one tenth of a second, and returns a {@code double}: the mechanism's speed
 *       in revolutions per minute. One tenth of a second is what CTRE's older velocity signals
 *       report over, which is why this conversion exists at all.
 *   <li><b>{@code rpmToTicksPer100ms}</b> — the inverse. Takes a {@code double} mechanism speed in
 *       RPM and returns a {@code double} tick delta per hundred milliseconds. This one returns a
 *       {@code double}, not an {@code int}: it is an answer about a rate, not a reading off a real
 *       encoder.
 * </ol>
 *
 * <h2>The one that matters</h2>
 *
 * <p><b>{@code rotationsFrom}</b> — takes a {@code java.util.function.DoubleSupplier} that reads
 * the raw tick count, and returns a {@code DoubleSupplier} that reports mechanism rotations.
 *
 * <p>Read that again. It takes a way of getting ticks and gives back a way of getting rotations.
 * It does not take a number and it does not return a number.
 *
 * <p>What it must do: every single time the returned supplier is asked for a value, it asks the
 * supplier it was given for a fresh tick count and converts that. Nothing is read when
 * {@code rotationsFrom} is called; everything is read when the result is used. Hand a command one
 * of these and it can ask fifty times a second and get fifty different answers.
 *
 * <p>This is the whole milestone in one method, and it is the shape {@code RobotPreference<T>} has
 * in the real codebase. See {@code READING.md}.
 */
public final class SensorProfileSpec {

  private SensorProfileSpec() {}
}
```

- [ ] **Step 4: Write `ContractProbe.java`**

Given, read-only, and the only place reflection is allowed. Its job is not to be clever — it is to turn "your class is missing, or named differently, or returns the wrong type" into a sentence the student can act on without a mentor.

Create `projects/m2-oop/src/test/java/frc/training/m2/ContractProbe.java`:

```java
package frc.training.m2;

import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.lang.reflect.Modifier;
import java.util.Arrays;
import java.util.function.DoubleSupplier;
import java.util.stream.Collectors;

/**
 * Finds the class you were asked to write, and says something useful when it cannot.
 *
 * <p>Part of the milestone — do not edit.
 *
 * <p>Why this exists: the contract test cannot mention {@code SensorProfile} by name in code,
 * because on a fresh clone that class does not exist yet and the test source would not compile.
 * Looking it up by name at run time is what lets this project build green before you have written
 * anything. It also means the names in {@code SensorProfileSpec} are the real contract: spell one
 * differently and the message below will tell you exactly what it looked for.
 */
final class ContractProbe {

  private static final String CLASS_NAME = "frc.training.m2.SensorProfile";

  private ContractProbe() {}

  /** Returns the student's class, or fails with instructions. */
  static Class<?> profileClass() {
    try {
      return Class.forName(CLASS_NAME);
    } catch (ClassNotFoundException e) {
      throw new AssertionError(
          "There is no class called "
              + CLASS_NAME
              + " yet. Read SensorProfileSpec.java — it describes exactly what to build — then"
              + " create SensorProfile.java beside it in src/main/java/frc/training/m2/.",
          e);
    }
  }

  /** Builds one, via the two-argument constructor the spec describes. */
  static Object newProfile(int ticksPerRotation, double gearRatio) {
    Class<?> type = profileClass();
    Constructor<?> constructor;
    try {
      constructor = type.getConstructor(int.class, double.class);
    } catch (NoSuchMethodException e) {
      throw new AssertionError(
          "SensorProfile needs a public constructor taking (int ticksPerRotation, double"
              + " gearRatio), in that order. Public constructors found: "
              + describeConstructors(type),
          e);
    }
    try {
      return constructor.newInstance(ticksPerRotation, gearRatio);
    } catch (InvocationTargetException e) {
      throw rethrow("the SensorProfile constructor", e);
    } catch (ReflectiveOperationException e) {
      throw new AssertionError("Could not build a SensorProfile: " + e, e);
    }
  }

  static double ticksToRotations(Object profile, int ticks) {
    return (Double) call(profile, "ticksToRotations", int.class, ticks, double.class);
  }

  static int rotationsToTicks(Object profile, double mechanismRotations) {
    return (Integer)
        call(profile, "rotationsToTicks", double.class, mechanismRotations, int.class);
  }

  static double ticksPer100msToRpm(Object profile, int ticksPer100ms) {
    return (Double) call(profile, "ticksPer100msToRpm", int.class, ticksPer100ms, double.class);
  }

  static double rpmToTicksPer100ms(Object profile, double mechanismRpm) {
    return (Double)
        call(profile, "rpmToTicksPer100ms", double.class, mechanismRpm, double.class);
  }

  static DoubleSupplier rotationsFrom(Object profile, DoubleSupplier rawTicks) {
    return (DoubleSupplier)
        call(profile, "rotationsFrom", DoubleSupplier.class, rawTicks, DoubleSupplier.class);
  }

  /** Fails if SensorProfile declares any field that is not private. */
  static void assertEveryFieldIsPrivate() {
    String offenders =
        Arrays.stream(profileClass().getDeclaredFields())
            .filter(field -> !field.isSynthetic())
            .filter(field -> !Modifier.isPrivate(field.getModifiers()))
            .map(Field::getName)
            .collect(Collectors.joining(", "));
    if (!offenders.isEmpty()) {
      throw new AssertionError(
          "Every field on SensorProfile must be private. These are not: "
              + offenders
              + ". Private fields mean there is exactly one place a value can change, which means"
              + " exactly one place to look when it is wrong.");
    }
  }

  private static Object call(
      Object profile, String name, Class<?> parameterType, Object argument, Class<?> returnType) {
    Method method;
    try {
      method = profile.getClass().getMethod(name, parameterType);
    } catch (NoSuchMethodException e) {
      throw new AssertionError(
          "SensorProfile needs a public method called "
              + name
              + " taking one "
              + parameterType.getSimpleName()
              + ". Public methods found: "
              + describeMethods(profile.getClass()),
          e);
    }
    if (!method.getReturnType().equals(returnType)) {
      throw new AssertionError(
          name
              + " must return "
              + returnType.getSimpleName()
              + ", but yours returns "
              + method.getReturnType().getSimpleName()
              + ". Re-read that entry in SensorProfileSpec.java.");
    }
    try {
      return method.invoke(profile, argument);
    } catch (InvocationTargetException e) {
      throw rethrow(name, e);
    } catch (IllegalAccessException e) {
      throw new AssertionError(name + " could not be called: " + e, e);
    }
  }

  /**
   * Surfaces whatever the student's own code threw, rather than burying it inside a reflection
   * wrapper. A student debugging their own ArithmeticException should see an ArithmeticException.
   */
  private static RuntimeException rethrow(String what, InvocationTargetException e) {
    Throwable cause = e.getCause();
    if (cause instanceof RuntimeException) {
      throw (RuntimeException) cause;
    }
    if (cause instanceof Error) {
      throw (Error) cause;
    }
    throw new AssertionError(what + " threw " + cause, cause);
  }

  private static String describeConstructors(Class<?> type) {
    String found =
        Arrays.stream(type.getConstructors())
            .map(c -> "(" + parameterList(c.getParameterTypes()) + ")")
            .collect(Collectors.joining(", "));
    return found.isEmpty() ? "none" : found;
  }

  private static String describeMethods(Class<?> type) {
    String found =
        Arrays.stream(type.getDeclaredMethods())
            .filter(m -> Modifier.isPublic(m.getModifiers()))
            .map(m -> m.getName() + "(" + parameterList(m.getParameterTypes()) + ")")
            .sorted()
            .collect(Collectors.joining(", "));
    return found.isEmpty() ? "none" : found;
  }

  private static String parameterList(Class<?>[] types) {

import java.util.function.DoubleSupplier;

public final class SensorProfile {

  private final int ticksPerRotation;
  private final double gearRatio;

  public SensorProfile(int ticksPerRotation, double gearRatio) {
    this.ticksPerRotation = ticksPerRotation;
    this.gearRatio = gearRatio;
  }

  public double ticksToRotations(int ticks) {
    return ticks / (double) ticksPerRotation / gearRatio;
  }

  public int rotationsToTicks(double mechanismRotations) {
    return (int) Math.round(mechanismRotations * gearRatio * ticksPerRotation);

    return mechanismRpm / 600.0 * gearRatio * ticksPerRotation;
  }

  public DoubleSupplier rotationsFrom(DoubleSupplier rawTicks) {
    return () -> rawTicks.getAsDouble() / ticksPerRotation / gearRatio;
  }
}

/**
 * Answers one question: how fast should the flywheel spin to score from here?
 *
 * <p>Ignite's real shooter has this shape. {@code ParabolicLaunchRequestBuilder} computes a launch
 * from physics and {@code MappedLaunchRequestBuilder} looks one up from a table somebody tuned on
 * the practice field, and the shooter uses either one without knowing which it has.

public interface RangeTable {

  /**
   * Returns the flywheel speed to use at a given distance.
   *
   * @param distanceMeters distance to the target, in metres
   * @return flywheel speed in RPM
   */

}
```

`src/main/java/frc/testout/t2/ParabolicRangeTable.java`:

```java
package frc.testout.t2;

/** A range table that computes a speed from a fitted curve. */
public final class ParabolicRangeTable implements RangeTable {

  private static final double CONSTANT_TERM = 2400.0;
  private static final double LINEAR_TERM = 180.0;
  private static final double QUADRATIC_TERM = 12.0;

  @Override
  public double rpmFor(double distanceMeters) {
    return CONSTANT_TERM
        + LINEAR_TERM * distanceMeters
        + QUADRATIC_TERM * distanceMeters * distanceMeters;
  }
}
```

`src/main/java/frc/testout/t2/MappedRangeTable.java`:

```java
package frc.testout.t2;

/** A range table that reads a speed off two measurements taken on the practice field. */
public final class MappedRangeTable implements RangeTable {

  private static final double NEAR_METRES = 2.0;
  private static final double NEAR_RPM = 3000.0;
  private static final double FAR_METRES = 6.0;
  private static final double FAR_RPM = 4200.0;

  @Override
  public double rpmFor(double distanceMeters) {
    if (distanceMeters <= NEAR_METRES) {
      return NEAR_RPM;
    }
    if (distanceMeters >= FAR_METRES) {
      return FAR_RPM;
    }
    double fraction = (distanceMeters - NEAR_METRES) / (FAR_METRES - NEAR_METRES);
    return NEAR_RPM + fraction * (FAR_RPM - NEAR_RPM);
  }
}
```
